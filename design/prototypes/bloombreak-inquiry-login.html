도움말과 문의 · 로그인

수정 이력 · v1.4.0 · 2026-11-22

v1.4.0: Google·Apple 모두 로그인 성공 안내를 4초간 표시하고 1:1 문의함으로 연결한다. Google로 계속하기 → 성공 안내만 표시하고 홈에 남던 동작은 문의함 열기로 변경한다. Apple 웹 인증 복귀에도 같은 성공 알림을 적용한다. 이미 로그인한 사용자의 같은 버튼도 문의함을 연다. 앱 시작의 저장된 로그인 복원·화면 복귀·중복 콜백은 문의함을 자동으로 열지 않는다. 웹·Android 내장 소스 적용 대상이며 새 발행 APK·실기기 전환 확인은 아직이다.

v1.3.0: Apple 전용 진입의 준비·취소·실패 상태에서도 일반 로그인 3개 버튼을 숨긴다. Apple로 다시 연결 / 다른 방법으로 로그인만 표시하며, 후자를 직접 눌렀을 때만 일반 선택을 연다. 운영 웹 수정 대상. 기존 APK의 호스팅 페이지에도 적용되며 설치본·실계정 성공은 별도 확인한다. Google 취소 오류와 테스트250 OAuth 등록은 미해결이며 재시도만으로 해결 표시하지 않는다.

v1.2.0: Apple 버튼 → 로그인 방법 3개 재표시 → Apple 재선택을, Apple 버튼 → Apple 공식 인증 페이지로 바로 이동으로 변경한다. 팝업 대신 같은 브라우저 탭에서 인증하고 성공하면 비공개 문의함으로 돌아온다. 취소·오류 시 다시 시도할 수 있다. Google의 250 별도 패키지 OAuth 등록은 미확인이다. 기존 D021/D022 보존. 발행 APK·실계정 완료 미확인.

v1.1.0: 더보기 맨 아래의 앱 정보 바로 밑에 별도 ‘심사 계정 로그인’ 행을 추가한다. 누르면 기존 심사용 아이디·비밀번호 양식으로 이동한다. 발행 APK·실기기 미확인.

D021/D022 도움말 화면 후속. 이전: Google로 계속 / 이메일로 계속, 가로 2열. 변경: Google로 계속하기 / Apple로 계속하기, 같은 크기의 세로 2행. Google은 앱의 기존 인증을 사용하고 Apple은 브라우저에서 Apple 공식 인증 페이지로 바로 연결한다. Apple 서비스 설정 전에는 문의함에서 비활성과 준비 중 안내를 표시한다. 기존 이메일 계정·문의 기록은 보존한다. 웹·Android 개발 소스 적용 대상이며 발행 APK·실기기·실계정 인증은 미확인이다. 이 영역은 기존 v12 시안의 문의 로그인 선택보다 우선한다.
