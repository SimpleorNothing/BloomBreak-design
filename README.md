# BloomBreak 디자인 시안

누구나 참고할 수 있는 BloomBreak 디자인 시안과 변경 이력입니다.

- [시안 관리 가이드](design/README.md): 버전 관리, 메뉴·문구 변경 이력, APK 구현 기준.
- [최신 시안 HTML — v12.2.3](design/prototypes/bloombreak-menu-v12.html): 시작 애니메이션과 파일 내 수정이력 포함.

## 시안 실행

GitHub의 **Code → Download ZIP**으로 내려받아 압축을 풀고 `design/prototypes/bloombreak-menu-v12.html`을 Chrome 등 브라우저로 여세요. 파일 내부에 이미지·GIF·스타일·스크립트가 포함되어 서버 없이 실행할 수 있습니다. 처음 열면 수정이력이 펼쳐져 있고, 접으면 시안을 편하게 조작할 수 있습니다. GitHub 파일 화면에서는 HTML이 직접 실행되지 않습니다.

APK는 최신 승인된 시안을 기본 기준으로 구현합니다. 명시적으로 디자인을 바꿀 때 시안과 내부 이력도 함께 갱신합니다. 시안 등록은 APK 반영 완료를 뜻하지 않습니다. 확인된 빌드 정보는 시안의 이력과 관리 가이드에 기록합니다.

v12.2.3은 앱에서 의도적으로 바꾼 시작 화면·더보기 아이콘·시간과 날씨를 더 옮긴 것이다. v12.2.1·v12.2.2는 앱에서 의도적으로 바꾼 5곳(더보기 그룹, 날씨와 시간 순서, 공간 만들기 문구, 응원하기 순서, 새 화분 심기의 사진 공간 타일)을 시안에 옮긴 것이며, 근거는 파일 안 수정이력에 있습니다. 시안 전체와 일치하는 APK 빌드는 아직 확인하지 않았습니다. 과거 메뉴별 변경 이력은 확인된 범위만 기록했습니다.
